# Wildgrove Bowl Co. 🥗

> **Clean, Wholesome Desk Lunches & Warm Grain Bowls**  
> Founded by an HR professional who understands the hustle of corporate life, our mission is to provide clean, healthy, and accessible desk lunches. We believe that eating healthy shouldn’t be a full-time job.

---

## 🌟 Features

- **Modern Responsive Landing Page**: Built with React 18, Tailwind CSS, Vite, and Lucide Icons.
- **Sticky Navbar**: Includes `[YOUR LOGO]` brand placeholder, smooth in-page navigation, and interactive delivery bag counter with subtotal.
- **Hero Section**: High-resolution salad imagery, value proposition, quick-add dish previews, and direct CTA.
- **Our Story**: Warm founder spotlight, authentic bio, and desk delivery mission.
- **Interactive Menu with Filters**:
  - `All`, `Veg Salads`, `Non-Veg Salads`, `Veg Bowls`, and `Non-Veg Bowls`.
  - Detailed macros on all 16 items (`Carbs: Xg | Protein: Xg | Vitamins: ...`).
- **High-Conversion "Order Now" Block**:
  - Dedicated Swiggy (Orange) and Zomato (Red) branded side-by-side ordering buttons.
- **Customization Lab**: Interactive bowl builder and drawer with dressing choices and add-ons.
- **Professional Footer**:
  - Social media brand icons (Instagram & Facebook).
  - "Contact Us" email support card.
  - "Weekly Healthy Living Tips" newsletter signup with confirmation.
  - Transparent nutritional values disclaimer.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/harshgupt1818/WILDGROVECO..git

# Navigate to project folder
cd WILDGROVECO.

# Install dependencies
npm install

# Start local development server
npm run dev
```

The app will be accessible at `http://localhost:3000/`.

### Production Build

```bash
npm run build
npm run preview
```
